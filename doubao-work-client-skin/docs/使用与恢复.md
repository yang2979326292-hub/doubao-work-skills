# 使用、恢复与故障定位

## 安装前

本工具为非官方外观增强，仅已验证当前Windows EXE客户端的主工作界面。不修改官方安装包或账号；使用本机调试接口，所以请只在信任的电脑上运行，不将端口暴露给网络。

完整解压最终ZIP到固定路径，保留src/和runtime/。不要在ZIP内部打开EXE，不要只复制EXE。每个解压目录拥有独立data，移动目录或另开临时解压版不会自动继承原配置。

## 首次配置

打开“豆包客户端皮肤-自动启动版.exe”，导入图片或视频。文件检查扩展名、文件头和150MiB上限，原文件不改。调整主题色、对话底色、0–100%统一不透明度、背景遮罩及铺满/完整显示，保存。

0%表示底色完全透明，100%完全不透明。文字仍清晰；左、中、右三栏共用一个值，内层底色透明以免相乘叠加。选中会话和悬停色是交互状态，不是遗漏的大面积底色。

## 第一次启用

点击“启用客户端换肤”。如果普通客户端仍在运行，等当前工作结束后通过菜单或托盘正常退出。仅点窗口X可能仍留托盘。面板等待完全退出后带回环调试参数启动，最多5分钟；不会强制关闭未保存任务。

“已保存”不等于“已应用”。查看最新状态与实际窗口效果，主窗口接口可用、媒体就绪和计算底色匹配才算生效。9333/9334的后台node目标不等于主窗口。

## 安装自动恢复入口

在固定解压目录运行：

```powershell
.\豆包工作-皮肤启动.exe --install-shortcuts
```

只匹配当前用户桌面和开始菜单中指向真实官方启动器的快捷方式；先完整备份和写入索引，再改目标并回读。原图标保留。找不到匹配入口时拒绝任意替代；重复安装拒绝覆盖旧备份。

以后从这些入口启动，自动读回皮肤，无启动动画。设置面板可以关闭，后台随客户端退出。原始EXE、未改任务栏、托盘、系统登录自启不涵盖。

## 日常调整与视频性能

从客户端“皮肤设置”打开面板，避免另一个临时解压目录。大体积高帧率视频仍会占用解码资源，推荐先在本地生成低码率副本，例如720p/24fps静音H.264；原片保留。面板没有内置自动转码，导入上限并非流畅播放保证。

## 常见问题

- **接口未开启**：保存无法改变已运行实例参数。使用正确入口并正常退出旧实例；不要反复保存或误连后台端口。
- **视频连接结束**：先确认版本包含分块传输；不要回退巨型整段base64逻辑。
- **解码失败/超时**：用兼容H.264 MP4或WebM，降低分辨率/帧率；查看本地transfer-error.json，不连续施压重试。
- **左侧更黑**：检查是否旧版本、多个解压目录或bg-inherit容器叠加；最终版regionVersion为4。不要把所有子节点opacity设为相同值。
- **重启皮肤消失**：先确认入口指向固定插件目录，而非官方原始EXE或临时ZIP目录。
- **关闭面板后停止**：确认不是旧“启用修复版”面板，使用自动启动版。
- **更新后失效**：客户端内部选择器可能变更，保留现场、停止重复传输，重新核对实际DOM。

## 恢复官方外观与卸载

先在面板点击“恢复官方外观”，等待实际恢复状态。若安装过入口，执行：

```powershell
.\豆包工作-皮肤启动.exe --restore-shortcuts
```

恢复前验证所有备份哈希及当前入口是否仍与安装记录一致；后续被用户修改的入口不会被静默覆盖。恢复后正常退出客户端，再从官方入口打开，关闭调试端口并清掉临时皮肤。

确认恢复后才删除插件目录。需要保留素材和配色时先备份整个data/；卸载和恢复默认不自动删除原素材。不要先删掉被快捷方式指向的文件夹。

## 本地诊断不外发

settings.json、status.json、worker.lock/worker.json、transfer-error.json、入口备份索引可能含本机路径或状态。诊断时先脱敏，不提交到GitHub。不要上传聊天截图、背景原片或账号信息。

# 豆包工作 Windows 客户端皮肤

**最终确认版：本地图片/视频背景 + 自定义主题色 + 三栏统一底色不透明度 + 启动自动恢复；无启动动画。**

这是非官方的本机客户端外观工具，不是网页版替代，不是已验证可被客户端加载的 Chrome 扩展。原生 WinForms 设置面板配合 Node 本地宿主，通过归属验证后的回环调试接口，为真实豆包工作主布局应用样式。不得把复制扩展目录或模拟页面测试当成客户端验收。

2026-11-03，委托用户在完整侧栏修复后确认“现在没有了”。确认范围是原先的左侧黑块，不代表所有平台、客户端版本、所有交互或长时间性能均已验证。

## 快速使用

1. 下载 `dist/豆包客户端皮肤-最终发布版.zip`，**完整解压到固定目录**，不要在压缩包内部直接打开EXE。
2. 打开 `豆包客户端皮肤-自动启动版.exe`，导入本地背景，选择主题色、对话底色、统一不透明度、遮罩与铺放方式，点“保存设置”。
3. 点“启用客户端换肤”。如客户端当前普通运行，等任务结束后从原生菜单或托盘正常退出；面板等待完全退出后带本机换肤参数打开，不强制终止任务。
4. 需要桌面/开始菜单自动恢复时，在解压目录执行下方安装命令。安装前备份原快捷方式，之后从“豆包工作”桌面或开始菜单入口打开。

```powershell
.\豆包工作-皮肤启动.exe --install-shortcuts
```

日常可关闭设置窗口，后台仍运行；客户端内“皮肤设置”按钮打开本机面板。后台在客户端退出后自行停止。**启动动画已按最终要求移除**。

## 能力和边界

- 本地 JPG/JPEG、PNG、WebP、GIF、MP4、WebM；导入上限150 MiB，具体编码是否可播取决于客户端解码器。
- 媒体只复制进本工具的 `data/media/`，不上传服务器，不覆盖原素材。
- 左、中、右工作区共用一个0–100%底色不透明度，文字不跟随透明；内层透明避免重复叠加。活动会话、悬停和按钮高亮保留。
- 视频静音循环，页面不可见时暂停；建议低码率720p/24fps等轻量副本。自动转码不是面板内置功能。
- 配置保存于本工具 `data/settings.json`，不是豆包原生配置。
- 仅已确认的桌面和开始菜单入口自动恢复。原始EXE、未修改任务栏/托盘、Windows登录自启不在覆盖范围内。
- 只作用于内部主工作布局，不保证嵌入文档/第三方iframe、原生标题栏、其他版本或macOS/ARM64兼容。
- 调试端口具有应用控制能力；仅允许回环监听并核对进程归属，不要交给不可信程序。

## 源码与构建

`src/` 为最终运行源码，`tests/` 为当前11项自动回归。仓库根目录的其他技能不受本项目影响；本目录是客户端工程归档，不是假装为官方插件或新技能入口。

```powershell
npm ci
npm test
python tools/build.py
```

构建需要Windows .NET Framework C#编译器和Python 3。开发测试需要Node及锁定的jsdom依赖。日常运行ZIP自带Node运行时，不需用户另外安装Node或Python。仓库源码中的PowerShell脚本使用UTF-8 BOM，因为当前EXE调用Windows PowerShell 5.1；本目录`.gitattributes`阻止Git破坏相关编码，不能为满足泛用格式约定去掉BOM而导致中文脚本失败。

## 1. 内容公式

**横屏氛围图负责"氛围"，长文案负责"故事与情绪"，BGM 负责"情绪基调"，结尾落到"人"。**

一条合格图文 = 16:9 电影感图 + ≤950 字深度文案 + 5 个真实话题 + 热门榜 BGM。

## 2. 开头钩子怎么写

前 3 行决定划走率，必须在读者划走前制造"不得不看"的理由：

- 历史向：抛反差/悬念/爽点。例："你一定背过苏轼，但你可能不知道，他曾差一点死掉。"
- 未来向：身份或认知反差。例："如果 AI 会做梦，它梦里第一个出现的，可能是地球。"
- 通用技巧：把名人/大概念拉到具体的人、具体的数字、具体的生死时刻；避免平铺直叙的背景介绍。

## 3. 长文案结构与语言

- 结构遵循配置中该母题的 `structure`，确保有起承转合和情绪反转。
- 语言：短句、口语化、有停顿；少用书面长句和抽象大词。
- 史料/科学概念要给出可信出处或合理推演，时间、地点、人物、数字具体。
- 结尾必须有"落点"：历史向给陪伴与启发，未来向收束到人并设问。
- 写完核对字数 ≤950，结尾句完整，防止被平台截断。

## 4. 话题与标题

- 标题 ≤20 字，前 7 字内出现钩子；不做标题党，承诺与正文一致。
- 5 个话题：1 个大领域 + 2 个具体主题 + 1 个情绪/人群 + 1 个基础（如 #原创），全部用平台真实存在的话题。
- 话题须在平台编辑器里成为"可点击"状态才算生效（操作见 creator-center-sop.md）。

## 5. BGM 选择

- 只从音乐面板「热门榜」选，不关键词搜索、不选冷门曲。
- 曲风与母题一致：历史向极简钢琴/大提琴；未来向空灵合成器+极简钢琴。
- 绑定后回读核对歌曲名，确认是目标曲目（防止误绑同名/相近歌曲）。

## 6. 两大母题模板

### 历史人文（至暗时刻 → 突围）
钩子（反差悬念）→ 史实铺垫（事件、年代、出处）→ 跌入谷底（具体困境）→ 转折与突围（行动、作品）→ 升华（金句 + 回到当下普通人）→ 评论引导/关注理由。

### 未来星际（AI 视角 → 落点到人）
钩子（身份/认知反差）→ 排比式未来清单（戴森球、火星城、意识上传等）→ 宏大叙事 → 收束到个体的人 → 结尾设问引发评论。

## 7. 数据反馈驱动的优化

- 划走率高 → 优先改开头钩子和首图。
- 文案展开率低 → 改开头几行的悬念，控制首屏信息密度。
- 点赞率低 → 强化情绪高点与金句，检查画面氛围。
- 评论为 0 → 结尾加开放式提问或可表态的选择。
- 吸粉为 0 → 强化系列化预告与明确关注理由，完善主页简介。
- 每次只动 1-2 个变量并记录，便于归因；阈值以配置 `goal.benchmark` 为准。
